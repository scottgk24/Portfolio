# Scott Kluempke — Portfolio

Interactive Mac desktop portfolio. Apps live in the dock — hover for a preview, click to open.

## Projects

- **PawPoints** — family chore tracker
- **SAGE** — household + business budgeting
- **Porchlight Studios** — photography marketing site
- **AutoCropper** — Mac desktop batch cropper
- **Paws & Pathways** — dog-walking booking site

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js (App Router), TypeScript, Tailwind CSS.
